# Toplist Maker — описание проекта

Живой документ: не жёсткая спецификация, а общее понимание продукта. Обновляем по мере идей и решений.

Приватные заметки (не в git): `docs/local/`.

## Зачем

Помочь человеку выстроить **личный рейтинг** чего угодно через сравнения «A или B», а не через ручную сортировку всего списка и не через чужие оценки.

Источник вдохновения: старый скрипт [ToplistMaker Shiki](https://github.com/Dan-Lore/projects/tree/main/ToplistMaker%20Shiki) — турнир по просмотренному аниме с Shikimori. Новый проект **не привязан к аниме**: домен любой (игры, фильмы, книги, еда, что угодно).

## Одной фразой

Инструмент, который через дуэли превращает набор элементов в честный персональный топ.

## Не цель (пока)

- Не клон tier list maker (перетаскивание по S/A/B).
- Не affiliate/SEO «toplist» сайт.
- Не обязательно социальная сеть вроде VAINKEURZ (мировые топы, Twitch) — если захотим, это отдельное решение позже.

## Стек

### Старт (фиксируем)

| Слой                 | Выбор                                                     | Зачем                                                        |
| -------------------- | --------------------------------------------------------- | ------------------------------------------------------------ |
| Тулчейн              | **Vite+** (`vp`: Vite 8 + Rolldown, Vitest, Oxlint/Oxfmt) | Один проверенный стек вместо зоопарка ESLint/Prettier/Vitest |
| UI                   | **Vue 3 + TypeScript**                                    | Удобный стейт для дуэлей, лёгкий SPA-MVP                     |
| Стейт                | **Pinia**                                                 | Топ, дуэли, прогресс                                         |
| Роутинг              | **Vue Router** (при желании file-based)                   | Экраны: список → дуэль → рейтинг                             |
| Хранение (приватное) | **Dexie** (IndexedDB)                                     | Надёжнее localStorage для данных топа                        |
| Тесты                | **Vitest** (из Vite+)                                     | Логика ранжирования                                          |

Скаффолд: через Vite+ (`vp create` / аналог под Vue). Хостинг при деплое выберет агент (Vercel / Cloudflare Pages и т.п.).

### По необходимости (агент предложит, когда пригодится)

| Идея                                  | Когда имеет смысл                                                    |
| ------------------------------------- | -------------------------------------------------------------------- |
| **Reka UI / shadcn-vue** (или аналог) | Нужен аккуратный UI карточек дуэлей без самописного design system    |
| **Nuxt**                              | Появится шаринг / SSR / серверная часть; для приватного MVP не тащим |
| **Vue Vapor**                         | Когда стабильно и даст выгоду; не основа сейчас                      |
| Другие UI/утилиты                     | По задаче — агент сообщит и предложит зрелый вариант                 |

### Не берём без нужды

- Angular, тяжёлый monorepo «на вырост», самописный тулчейн вместо Vite+

## Стоимость: можно ли бесплатно

**Да — для MVP и долгое время после, если не гнаться за кастомным доменом и тяжёлым бэкендом.**

| Что                                | Бесплатно?     | Комментарий                                                           |
| ---------------------------------- | -------------- | --------------------------------------------------------------------- |
| Код + GitHub                       | Да             | Публичный репо                                                        |
| Хостинг сайта                      | Да             | Vercel Hobby / Cloudflare Pages / GitHub Pages                        |
| HTTPS                              | Да             | Входит в хостинг                                                      |
| Данные пользователей без аккаунтов | Да             | Браузер: localStorage / IndexedDB                                     |
| Лёгкий бэкенд + БД позже           | Да, с лимитами | Cloudflare D1/Workers, Supabase free, и т.п.                          |
| Кастомный домен                    | Обычно нет     | ~стоимость домена в год; можно жить на `*.vercel.app` / `*.pages.dev` |

Самый дешёвый путь к «готовому вебу»: клиентское приложение + деплой на free-tier, без своего сервера. Аккаунты и облако — когда появятся реальные пользователи и потребность.
